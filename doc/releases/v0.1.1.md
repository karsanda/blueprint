Fixes and hardening after v0.1.0, and one change to the keys: the layout presets are gone.

## What changed

- **No more presets.** The Layout menu and Ctrl+Shift+1 to 4 are removed. Arrange the panes by hand; Blueprint remembers them per Folder. Ctrl+Shift+1 to 4 now reach the program in the terminal (#48).
- **This session survives a reopen.** A Claude tab that resumes its conversation lists the Changes from before Blueprint closed, still credited to Claude (#27).
- **One Blueprint per Folder.** A second window on a Folder that is already open starts new conversations and says why, and leaves the first window's layout alone (#29).
- **A question shows Needs you.** When Claude ends its turn on a question in plain text, the session shows Needs you, with the desktop notification (#16).
- **Blocked hooks are named.** When Claude Code's settings turn off its hooks (`disableAllHooks`, `allowManagedHooksOnly` or `allowedHttpHookUrls`), the Claude pane names the setting and its file. Without the hooks, Blueprint cannot see the session's status or tell which Changes are Claude's (#15).

## Fixes

- **Pop-out windows:**
  - their pages carry the same content security policy as the main window, and can no longer reach its API (#37);
  - they load their own page only once (#45);
  - closing one releases its key listener (#38).
- **Workspace keys** no longer act behind the close question or an open menu (#39).
- **Working in a pop-out window** counts as Blueprint being in front: no desktop notification, and the review refreshes when it comes forward (#43).
- **Quitting** while a Claude session was still starting could leave its terminal running after Blueprint closed. No terminal starts once Blueprint quits.
- **The review across a reopen:** a Git command left running by the last run can no longer break the next run's review.

## Install

Blueprint needs [Claude Code](https://docs.anthropic.com/en/docs/claude-code), installed and signed in.

**Ubuntu** (amd64): download `blueprint_0.1.1_amd64.deb`, then:

```sh
sudo apt install ./blueprint_0.1.1_amd64.deb
blueprint ~/path/to/project
```

This also upgrades v0.1.0 in place. It also adds Blueprint to the app menu, which opens a folder picker.

If apt ends with "Download is performed unsandboxed as root", the install still worked. apt's own user can't read your home folder, so apt read the file as root.

**macOS** (Apple Silicon):
1. Open `Blueprint-0.1.1-arm64.dmg` and drag Blueprint into Applications, replacing v0.1.0 if you have it.
2. The app is not signed with a Developer ID, so allow its first open: open it once, then choose Open Anyway in System Settings › Privacy & Security. Or run `xattr -dr com.apple.quarantine /Applications/Blueprint.app`.
3. For the `blueprint` command, link it once into a folder on your `PATH`. A link made for v0.1.0 keeps working.

   ```sh
   mkdir -p ~/.local/bin
   ln -s /Applications/Blueprint.app/Contents/Resources/bin/blueprint ~/.local/bin/blueprint
   blueprint ~/path/to/project
   ```

   A stock Mac has no `~/.local/bin` on its `PATH`. Add `export PATH="$HOME/.local/bin:$PATH"` to `~/.zprofile`, or link into `/usr/local/bin` with `sudo` instead.

On both, `blueprint <folder>` gives the prompt back at once, and each Folder opens in its own window. Layouts and conversations saved by v0.1.0 carry over.

## Keys

| Keys | What they do |
| --- | --- |
| Ctrl+Shift+C / Ctrl+Shift+V (and Cmd+C / Cmd+V on macOS) | copy and paste in a terminal |
| Ctrl+Shift+H / J / K / L | move the keyboard to the pane on the left / below / above / right |
| Ctrl+Shift+Alt+H / J / K / L | move the tab to that pane |
| Ctrl+Tab / Ctrl+Shift+Tab | next / previous tab |
| Ctrl+Shift+T / Ctrl+Shift+N | new shell / new Claude session |
| Ctrl+Shift+Z | zoom the pane |

On macOS, Option acts as Alt in terminals. No workspace key acts while the close question or a menu is open.

## Known gaps

- **Not checked by hand on a Mac yet:**
  - the first open after Gatekeeper;
  - desktop notifications (#18, #44);
  - Claude Code finding your tools when Blueprint is opened from Finder.

  Both test suites pass on macOS in CI.
- When an MCP server asks you for input, Needs you shows about 6 seconds after the question: Claude Code reports it only then.
- Claude Code's folder-trust question and its sign-in still show the session as idle: no hook reports them (#16).
- A `git gc` that removes content only your repository kept can stop the review listing a range's Changes (#52).
- A popped-out terminal may pause while the main window is minimized.
